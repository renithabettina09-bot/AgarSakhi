# AgarSakhi: Smart Agarbatti Drying and Packaging System

## Overview

AgarSakhi is an intelligent system designed to improve agarbatti drying and packaging through smart sensing, automated control, and moisture verification.

## Key Features

- Multi-point temperature and humidity monitoring
- Moisture and weight sensing
- Intelligent drying control
- Automated heater and blower operation
- Solar thermal with AC/Battery backup
- Automatic dryness verification
- Controlled cooling and packaging

## Workflow

**Start → Conditioning → Drying → Verification → Cooling → Packaging → Ready**
